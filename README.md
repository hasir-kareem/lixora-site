# Series posters

Put series poster images in this folder.

- Size: about 400 x 600 px (portrait), JPG or PNG, under 200 KB.
- File names: lowercase letters, numbers and dashes, no spaces. Example: `series-name.jpg`
- After adding a poster, add a line for it in `catalog.js` (in the website folder):

`{ title: 'Series Name', year: 2026, poster: 'posters/series/series-name.jpg' }`

Only use posters you have the right to share, such as official press images.
